# TindaTrack

TindaTrack is a mobile order management app for sellers. It helps organize products, prepare customer orders, and keep checkout records in one place.

## Features

- Organize products by category
- Add product photos and wholesale prices
- Mark products as in stock or out of stock
- Set quantities and units for products
- Build customer orders and calculate totals automatically
- Save customer and store contact details with each order
- Review checkout history and mark orders as delivered
- Browse categories, products, cart items, and order history with pagination

## Built With

- React Native
- Expo
- Expo Router
- TypeScript
- AsyncStorage

## Getting Started

### Requirements

- Node.js
- npm
- Expo Go, an Android emulator, an iOS simulator, or a web browser

### Install and run

```bash
npm install
npx expo start
```

Use the Expo terminal prompts to open the app on your preferred platform.
